# Additive GP 诊断与改进

## 已排除与待检验的问题

已有解析梯度测试、scikit-learn 固定参数及优化结果对照都通过。
此前 80 维配对优化中，本库与 scikit-learn 的 LML 和预测很接近，
因此本次优先检验统计建模与参数估计问题，而不是更换优化器。

原模型将 80 个变量分成 20 个四维组，每组独立幅度和各向同性长度尺度，另加噪声，共 41 个超参数。
在原实验中，一些分量幅度接近下界、噪声估计很低；需要验证这是否对应过拟合。
组内使用单个长度尺度也可能无法有效表达不同坐标的重要性。

本次改进仍是同一个联合 GPR 上的子核求和，没有为分量重复拟合完整标签。
新增两个可选功能：

- `SharedAdditiveKernel<K>`：各组共享核超参数，解析梯度按组求和。
  这共享的是协方差参数，各组仍对应不同的潜在函数，不强制它们的函数值相同。
- `GPROptions::prior`：对数超参数的 Gaussian 先验，以 MAP 目标抑制极端参数估计。
  先验默认关闭，`log_marginal_likelihood()` 保持纯 LML 语义。

## 在测试前固定的实验方案

实验代码与此方案在正式测试前提交。开发阶段使用旧种子 11 的训练集做三折筛选，
快速代码检查使用种子 101。正式实验使用此前未用于方案开发的种子 **1001、2003、3007**。
不将旧测试集或新测试集标签用于选择候选或调节先验宽度。

| 候选 | 核结构 | 80 维参数数 |
| --- | --- | --- |
| independent | 原独立幅度、独立各向同性长度尺度 | 41 |
| shared_iso | 共同幅度、共同各向同性长度尺度 | 3 |
| shared_ard | 共同幅度、共同的四个组内位置长度尺度 | 6 |
| map_0.5 | 原独立参数 + log 参数先验宽度 0.5 | 41 |
| map_1.0 | 原独立参数 + log 参数先验宽度 1.0 | 41 |
| map_2.0 | 原独立参数 + log 参数先验宽度 2.0 | 41 |

所有候选使用 RBF、相同初始化规则、最多 500 次 L-BFGS-B 迭代、梯度容差 `1e-5`、
函数容差 `1e-8`、单一起点。原模型的设定沿用前次实验。
共享模型的每组幅度边界为原总幅度边界除以组数，使总幅度边界仍为 `[1e-5,100]`。
初始总幅度均为 1，长度尺度均为 0.7，噪声方差为 0.001。
MAP 先验中心为初始化的 log 参数，各组幅度和长度尺度使用表中宽度；噪声先验宽度固定为 1.5。

每个数据集采用相同的三折划分，以合并全部留出预测后的 RMSE 选择一个候选。
每折独立进行 y 归一化、超参数优化及预测。选定候选后才在完整训练集重拟合并评估测试集。
所有候选的测试结果都保留用于消融分析，`cv_selected` 只来自训练集内选择，
不取测试集上表现最好的候选。

正式实验共 27 个数据集，每个有 6 个候选、3 次折内拟合和 1 次完整重拟合，共 648 次拟合：

- 原加性函数：D=4、20、80，训练样本 128、256，每个设置三个种子。
- 异质加性函数：D=80，训练样本 128、256，每个设置三个种子。
  在原组内函数的四个输入位置上分别乘以循环变化的 `0.5+0.4*((group+position) mod 5)`，
  引入组间长度尺度和坐标重要性的差异，测试共享参数假设的限制。
- 稠密交互函数：D=80，训练样本 256，每个设置三个种子，沿用原 Fourier 特征对照。

每个数据集有 1024 个独立测试点，测试标签为无噪声真值；训练标签加入标准差 0.03 的噪声。
代码复用 `problems.hpp` 中的原数据生成函数，原实验的快速回归对照已核实不变。

## 指标与复现

```bash
cmake --preset release -DCMAKE_CXX_STANDARD=14 -DSUPER_GPR_BUILD_EXPERIMENTS=ON
cmake --build --preset release --target additive_improvement
./build/release/bin/additive_improvement > experiments/additive_improvement_results.csv
python3 experiments/summarize_improvement.py experiments/additive_improvement_results.csv \
  --output experiments/ADDITIVE_IMPROVEMENT_RESULTS.md
```

快速代码检查使用 `--quick`，只使用开发用种子 101、64 个训练样本和 256 个测试点。

原始记录包含每折及每次重拟合的误差、参数、纯 LML、MAP 目标、优化器状态、时间和训练误差。
额外记录恢复原始尺度的噪声标准差和有效自由度：

```text
df = trace(K_signal * (K_signal + (noise + alpha) I)^-1)
```

该自由度用于诊断插值程度，不等于超参数数量。汇总脚本核对 MAP 惩罚、CV 分数重建、
样本计数、候选完整性、选择是否只依赖 CV 分数，以及有效自由度范围。
训练误差与测试误差的差异、噪声估计和消融结果共同支持诊断，不从单个指标断言因果。

汇总表分别报告完整重拟合时间与全部 CV 拟合时间。
共享模型的一次拟合即使更快，模型选择流程仍需额外 CV 成本。
MAP 和共享参数均为可选假设，不自动覆盖原有模型。

## 数学与解释范围

超参数越多，最大化 LML 的点估计也可能过拟合；Gaussian 先验的 MAP 是一种收缩方法，
并非对超参数进行完整 Bayesian 积分。参见
[GPML 第五章](https://gaussianprocess.org/gpml/chapters/RW5.pdf)。
组内坐标具有可比较的作用时，共享 ARD 才有直接含义；异质变量组可能需要独立参数或弱收缩。
本实验不学习变量分组，不自动消除跨组交互，也不承诺对任意高维黑盒达到低维精度。
中心化 ANOVA 核可作为后续候选，相关背景见
[Durrande et al.](https://arxiv.org/abs/1106.3571)；本次没有把该方法当作已经实现的改进。
